# 주차 위치 찾기 엔진 — 시나리오 100선

> 앱만으로(하드웨어 없이) "차에서 내린 순간부터 여러 신호를 조합해 기억하고, 돌아올 때 안내하는" 엔진이 대응해야 할 상황 목록입니다.
> 각 시나리오는 **무엇이 깨지는지**와 **엔진의 대응**, **담당 모듈**을 함께 적었습니다. 엔진 구조는 [engine-design.md](./engine-design.md)를 참고하세요.

## 모듈 약어

| 약어 | 모듈 | 역할 |
|---|---|---|
| SB | Sensor Buffer | 센서 수집, 10분 되감기 링버퍼, 기기별 센서 능력표 |

## A. 주차 감지·트리거 (15)

| ID | 시나리오 | 무엇이 깨지나 | 엔진 대응 | 모듈 |
|---|---|---|---|---|
| A01 | 기본: 차 블루투스 연결 상태로 지하 주차 → 시동 끔 → 걸어 나감 | — (기준 시나리오) | BT 해제 + 걸음 시작으로 주차 확정, 링버퍼에서 진입 경로 복원 | PD, SB |
| A02 | CarPlay / Android Auto 연결 해제 | iOS는 일반 BT 해제 이벤트를 받기 어려움 | CarPlay 해제(단축어 자동화 → App Intent), Android Auto 해제를 BT와 같은 강한 증거로 취급 | PD |
| A03 | 블루투스를 연결하지 않는 차/습관 | 강한 증거 없음 | 활동 인식(차량→도보) + GNSS 속도 0 + 차량 램프 하강 패턴을 합산 점수로 확정, 신뢰도 한 단계 하향 | PD, CF |
| A04 | 동승자로 탑승(내가 운전 안 함) | 내 폰은 차 BT 미연결 | A03과 같은 방식으로 기록, '동승' 태그. 가족 차면 그대로 안내 가치 있음 | PD |
| A05 | 주차 후 차 안에서 10~20분 통화/휴식 | BT 해제 시점 ≠ 실제 하차 시점 | 원점·기압 기준을 'BT 해제'가 아니라 '첫 걸음 시작'으로 잡음. 최대 60분 대기 | PD, SB |
| A06 | 시동 켠 채 잠깐 내림 → 멀어지면서 BT 끊김 | 끊긴 지점은 이미 차에서 10m 떨어진 곳 | 링버퍼를 '차량 정지 후 첫 걸음' 시점까지 되감아 원점 보정 | SB, PD |
| A07 | 주행 중 BT 순간 끊김(글리치) | 주차 오탐 | 차량 진동·GNSS 속도 지속·걸음 없음 → 부정 증거로 무시 | PD |
| A08 | 폰을 차에 두고 내림 | 걸음이 없어 기록 이상 | 걸음 미발생 + 정지 지속 → 원점 = 폰 위치 = 차로 두고 알림 없음 | PD |
| A09 | 만차라 여러 층을 돌다가 주차 | 차량 경로가 길고 층 변화가 여러 번 | 경로 합이 아니라 최종 정지 시점의 '순 높이 변화'만 사용 + 도보 측정과 교차 검증 | VS |
| A10 | 주차 후 차를 다시 옮김(이중주차 빼주기, 자리 이동) | 기존 기록이 낡음 | 차 재연결·차량 이동 감지 → 새 기록으로 교체, 이전 기록 폐기 | PD, SM |
| A11 | 평행(이중)주차로 남이 내 차를 밀어 몇 m 이동 | 실제 위치와 수 m 오차 | 도착 반경을 오차보다 크게(≥4m) 잡고, 도착 모드에서 사진·비상등 안내 | GD |
| A12 | 발렛: 지상 입구에서 내리고 직원이 주차 | 내 경로 ≠ 차 위치 | 'GNSS 양호한 지상에서 하차 + 지하 진입 이력 없음' → 발렛/지상 하차로 분류, 안내 대신 '맡긴 곳' 표시 | PD, UX |
| A13 | 기계식/타워 주차 | 차가 기계로 이동 | 하차 지점 = 출차 게이트로 기록, 사이트를 '기계식'으로 학습(1회 태그) | SM, UX |
| A14 | 가족이 내 차를 가져가 다른 곳에 주차 | 내 폰은 알 수 없음 | **앱만으로는 해결 불가 영역으로 명시.** 기록 시각을 항상 표시('어제 19:30'), 가족 공유 시 가족 폰 기록으로 갱신 | UX, SM |
| A15 | 차가 여러 대 / 렌터카·카셰어링 | 어느 차의 기록인지 모름 | 차별 기록(BT 기기 ID가 키). BT 없는 차는 '임시 차량'으로 기록, 1탭으로 변경 | PD, UX |

## B. 층 판별 (20)

| ID | 시나리오 | 무엇이 깨지나 | 엔진 대응 | 모듈 |
|---|---|---|---|---|
| B01 | 저녁 주차 → 다음 날 아침 복귀(날씨 변화) | 절대 기압을 비교하면 2~3개 층 오차 | **절대값 비교 금지.** 엘리베이터 탑승처럼 짧은 구간의 변화량을 앵커 체인으로 연결 | VS, AG |
| B02 | 태풍·한랭전선 등 급격한 기압 변화 | 짧은 구간에도 추세 오차 | 정지 구간에서 기압 추세(Pa/분)를 추정해 수직 구간에서 빼기 | VS |
| B03 | 환기팬·방화문 개폐로 순간 압력이 튐 | 가짜 층 이동 | 수 초 안에 원래대로 돌아오는 변화는 제거 + 구간 '평탄부 중앙값' 차이로 계산 | VS |
| B04 | 엘리베이터 샤프트·연돌효과(고층) 압력 편차 | 엘리베이터 안 측정값 왜곡 | 높이는 엘리베이터 안이 아니라 '내려서 걷기 시작한 뒤의 평탄부'에서 측정 | VS |
| B05 | 경사지 단지: 한쪽 입구는 1층, 반대쪽 입구는 B1 | '지상 = 1층' 가정 붕괴 | 내부적으로 원시 높이차(m)만 저장, 층 이름은 사이트별로 학습(사진 글자 인식·1탭 교정) | SM, VS |
| B06 | 주차장 층고 ≠ 주거층 층고 | 높이 ÷ 층고 계산 오류 | 집↔차는 '층수'가 아니라 원시 높이차로 매칭. 층 이름 계산에는 주차장 층고만 사용 | VS, SM |
| B07 | 스플릿 레벨(반 층씩 엇갈린 주차장) | 균일 층고 가정 붕괴 | 여러 번 주차한 높이값을 군집화해 그 사이트의 실제 레벨 집합을 학습 | SM |
| B08 | 나선형 램프로 차가 내려감 | 걷기 전부터 정보가 필요 | 링버퍼의 차량 하강 높이(F_drive)를 1차 추정으로 사용 | VS, SB |
| B09 | 바닥 자체가 경사진 주차장(층 경계 모호) | 층 양자화 실패 | 연속 높이를 가장 가까운 학습 레벨에 매칭, 확신이 낮으면 '약 B2' + 사진 | VS, CF |
| B10 | 계단으로 걸어 올라감 | 엘리베이터와 패턴이 다름 | 걸음 + 느린 수직 속도 + 층참 정지 패턴으로 계단 분류, 높이는 평탄부 차이로 | VS |
| B11 | 에스컬레이터(마트) | 걸음 없이 일정 속도로 상승 | 수직 속도 일정·걸음 거의 없음 → 에스컬레이터로 분류 | VS |
| B12 | 엘리베이터가 여러 층에 정차(출근 시간) | 구간 분할이 복잡 | 정차마다 평탄부로 나눠 합산, 최종 순 변화만 사용 | VS |
| B13 | 버튼을 잘못 눌러 올라갔다가 다시 내려옴 | 경로 합계 오류 | 경로 길이가 아니라 순 높이 변화만 사용 | VS |
| B14 | 지하 → 지상 → 다른 동 엘리베이터 | 기준 연결이 끊김 | GNSS가 잡히는 지상 구간을 앵커로 끼워 넣어 체인 유지 | AG |
| B15 | 기압계 없는 폰 | 핵심 센서 부재 | 대체 수단: 나선 램프 회전 수(자이로 360° ≈ 1개 층), 엘리베이터 탑승 시간, 사진 글자 인식, 1탭 확인. 신뢰도 하향 | VS, CF, UX |
| B16 | 기압계 노이즈가 큰 기종/오프셋 | 측정 불안정 | 정지 상태 분산으로 자가진단 → 품질이 낮으면 가중치 하향 | SB, CF |
| B17 | 차 안 에어컨으로 실내외 압력 차 | 원점 기압 오차 | 원점 기압은 차 안이 아니라 '문 열고 걷기 시작한 뒤' 값 사용 | VS |
| B18 | 지하 5층 깊은 주차장 / 50층 이상 고층 | 큰 높이차·고속 엘리베이터 | 평탄부 기반이라 누적 오차 없음, 수직 이동 중에는 샘플링을 높임 | VS, SB |
| B19 | 지상 다층 주차빌딩/옥상 | 층이 양수 | 같은 엔진, 라벨만 '3F/R'. 옥상은 GNSS도 사용 | VS, SM |
| B20 | 같은 층인데 동 사이 연결 경사로로 높이가 조금 다름 | 가짜 층 변경 | 층 변경 판단에 히스테리시스(0.6개 층 이상 변해야 인정) | VS |

| C12 | 지상 평면 주차장(GPS 가능) | — | GNSS 직접 사용 + 도보 추적으로 보정 | LOC |
| C13 | 지하에 중계기 등으로 GPS가 잡히는 듯한 곳 | 낡은/가짜 위치 | 품질 게이트 + 기압상 지하이면 GNSS 무시 | SB |

| C15 | 무빙워크 | 걸음 없이 수평 이동 | 해당 구간 길이를 '미상'으로 표시, 다음 앵커에서 회복 | PDR, CF |
