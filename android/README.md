# 파킹메모 테스트 앱 (Android)

앱만으로 "몇 층, 어느 쪽"을 기억하고 안내하는 엔진을 실제 주차장에서 검증하기 위한 테스트 빌드입니다.
설계: [`docs/parking-finder/engine-design.md`](../docs/parking-finder/engine-design.md) · 시나리오: [`scenarios.md`](../docs/parking-finder/scenarios.md)

## 1. 설치

1. 폰 브라우저에서 이 저장소의 **Releases → `test-apk-latest`** 를 열고 `parking-memo-test.apk` 를 받습니다.
   (저장소가 비공개라면 GitHub에 로그인한 브라우저에서 열어야 합니다. 또는 Actions 실행 결과의 `parking-memo-test-apk` 파일을 PC에서 받아 폰으로 옮겨도 됩니다.)
2. "출처를 알 수 없는 앱 설치"를 한 번 허용하고 설치합니다.
3. 새 빌드는 기존 앱 위에 그대로 설치됩니다. 저장된 기록과 로그는 유지됩니다.

**필요 조건**: Android 10 이상, **기압계가 있는 폰**(갤럭시 S 시리즈, 픽셀 등). 기압계가 없으면 처음 설정 화면에 빨간 글씨로 표시됩니다.

## 2. 처음 설정 (한 번만)

| 단계 | 하는 일 |
|---|---|
| 1. 권한 허용 | 위치, 걸음 감지(신체 활동), 근처 기기(블루투스), 알림 |
| 2. 위치 '항상 허용' | 시스템 설정 화면에서 "항상 허용" 선택 |
| 3. 배터리 최적화 제외 | "허용" 선택. 삼성은 추가로 *설정 → 배터리 → 백그라운드 사용 제한*에서 이 앱을 "제한 없음"으로 |
| 4. 내 차 블루투스 고르기 | 목록에서 차 오디오를 한 번 탭 |

2, 3번을 건너뛰면 Android가 백그라운드 실행을 막아서, 주차할 때 "탭해서 기록" 알림이 뜰 수 있습니다.

## 3. 테스트 방법

### A. 실제 사용 (자동)

1. 평소처럼 차에 타서 블루투스가 연결되면 상단에 "운전 중" 알림이 뜹니다.
2. 지하주차장에 주차하고 시동을 끄고 내립니다. **아무것도 누르지 않습니다.** 몇 걸음 걸으면 **"드르륵, 드르륵" 두 번 진동**하며 기록이 시작됩니다. 무음 모드에서도 울립니다. 동시에 **"B4에 주차했나요? [맞아요] [B5] [B3]"** 알림이 뜹니다. 기둥 표시를 보고 버튼 하나만 누르면 층이 확정되고, 같은 주차장에서는 다음부터 그 층을 먼저 추천합니다.
3. 엘리베이터를 타고 집(또는 목적지)까지 갑니다. 도착 후 몇 분 지나면 "B3에 주차했어요" 알림이 뜹니다.
4. 다음에 차를 찾으러 갈 때, 집을 나서기 전에 앱에서 **[차 찾기 시작]** 을 누릅니다.
5. 엘리베이터에서 층 안내를 보고, 내리면 화살표와 거리를 따라 갑니다.
6. 시동을 걸어 차 블루투스가 연결되면 안내가 자동으로 끝나고, 그때 위치가 정답 데이터로 저장됩니다.

### B. 차 없이 빠르게 (수동)

1. 주차장에서 차 옆에 서서 **[지금 주차한 것으로 기록 시작]**.
2. 엘리베이터까지 걸어가서 다른 층(1층 등)으로 이동한 뒤 **[하차 기록 끝내기]**.
3. 바로 **[차 찾기 시작]** 을 누르고 다시 차로 돌아가 봅니다.

### 걸을 때 폰 자세

**평소처럼 들고 다니면 됩니다.**
- 내릴 때 주머니나 가방에 넣어도 됩니다. 돌아올 때 엘리베이터에서 나와 처음 3 m를 걷는 방향으로 저장된 경로를 자동으로 맞춥니다. 안내 화면 아래에 "방향 보정 +90°"처럼 표시됩니다.
- 걷다가 폰을 꺼내거나 넣어도 경로가 꺾이지 않게 보정합니다.
- 돌아올 때는 화면을 보며 걸어야 화살표가 정확합니다.

### 먼저 센서부터 확인하세요

홈 화면 **[센서 확인]** 을 열고 엘리베이터를 한 번 타 보세요. "높이 변화"가 한 층에 약 3 m씩 바뀌고, 걸으면 걸음 수가 올라가야 합니다. 둘 중 하나라도 안 바뀌면 그 폰으로는 테스트가 어렵습니다.

### 알림에서 바로 찾기

주차가 기록되면 알림창과 잠금화면에 **"B3에 주차했어요 · [차 찾기]"** 카드가 남습니다. 집을 나서면서 이 버튼을 누르면 앱을 열지 않고 바로 안내가 시작됩니다.

## 4. 테스트 후 보내주실 것

1. 홈 화면 **[기록 파일 내보내기]** → 카카오톡이나 메일로 공유하면 zip 파일 하나가 나갑니다.
2. 함께 적어주시면 좋은 것:
   - 실제로 주차한 층과 기둥 번호
   - 앱이 보여준 층
   - 안내가 끝났을 때 차까지 실제로 남은 거리(대략)
   - 폰을 어떻게 들고 걸었는지 (손 / 주머니 / 가방)

로그는 엔진의 [`LogReplay`](engine/src/main/kotlin/com/parkingmemo/engine/LogReplay.kt)로 그대로 재생할 수 있어서, 주차장에 다시 가지 않고도 임계값을 조정해 볼 수 있습니다.

## 5. 알려진 한계 (이번 버전)

- 나갈 때와 **다른 엘리베이터**로 돌아오면 층 안내만 정확하고 화살표는 틀릴 수 있습니다 (시나리오 E03).
- 엘리베이터에서 나와 바로 크게 꺾어야 하는 구조라면 방향 자동 보정이 늦게 걸릴 수 있습니다. 안내 화면 아래 "방향 보정" 표시를 확인해 주세요.
- 걸음 센서가 없거나 '신체 활동' 권한을 거부하면 가속도 센서로 걸음을 셉니다. 거리 오차가 조금 커질 수 있습니다.
- 처음 가는 주차장은 층고를 3.0 m로 가정합니다. 층이 틀리면 홈 화면에서 한 번 고치면 그 주차장은 다음부터 반영됩니다.
- iOS 버전, 엘리베이터를 타면 저절로 안내가 시작되는 기능, 기둥 사진 글자 인식은 아직 없습니다.

## 6. 개발

```bash
cd android
./gradlew :engine:test          # 엔진 시나리오 테스트 (JVM만 있으면 됨)
./gradlew :app:assembleDebug    # 앱 빌드 (Android SDK 필요)

# 앱에서 내보낸 로그 재생: 주차 로그로 기록을 다시 만들고, 안내 로그를 초 단위로 출력
./gradlew :engine:run --args="logs/20261110-183012-park.csv logs/20261111-080011-guide.csv"
```

GitHub Actions(`.github/workflows/android.yml`)가 `android/` 변경을 푸시할 때마다 엔진 테스트와 APK 빌드를 하고, `test-apk-latest` 릴리스를 갱신합니다.
